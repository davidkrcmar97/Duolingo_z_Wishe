# Duolingo z Wishe 🦉

Interaktivní webová aplikace pro učení angličtiny inspirovaná Duolingem. Rozhraní je česky.

## Funkce
- Výběr vlastní pokročilosti (začátečník / mírně pokročilý / pokročilý)
- Cesta lekcí rozdělená do jednotek, lekce se odemykají postupně
- Cvičení: výběr překladu, skládání věty, psaní odpovědi
- XP, denní série (streak) a srdíčka, postup se ukládá v prohlížeči
- Výslovnost anglických slov (Web Speech API)

## Spuštění
Stačí otevřít `index.html` v prohlížeči – žádná instalace ani server.

## Technologie
Čisté HTML, CSS a JavaScript v jednom souboru, bez závislostí.
